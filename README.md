# 📝 Interactive Registration Form

FORM-VALIDATION

A clean, responsive, and user-friendly registration form built using _HTML5, CSS3, and JavaScript_ for my _FSWD (Full-Stack Web Development)_ course project.

---

## 🎯 Purpose

This project was built to demonstrate client-side form validation, clean user interface design, and dynamic interactive feedback without relying on external libraries or frameworks.

---

## ✨ Key Features

- _Real-time Input Validation:_ Validates required fields, email formatting, and matching passwords before submission.
- _Responsive Design:_ Optimized to look great on desktop, tablet, and mobile devices.
- _Interactive UX:_ Highlights input errors and displays helpful dynamic visual messages.

---

## 🛠️ Tech Stack

- _HTML5:_ Semantic form markup and structure.
- _CSS3:_ Flexbox layout, clean styling, and input focus states.
- _JavaScript (ES6):_ DOM manipulation, event handling, and form validation rules.
